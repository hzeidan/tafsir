# فوائد التفاسير

صفحة HTML + JavaScript لعرض فوائد التفسير لكل آية من سورة، مع تصفية حسب **التفسير** و**نوع الفائدة** و**نطاق الآيات** و**البحث النصي**، وتنزيل **CSV** للعرض المصفّى فقط.

- كل فائدة مذكورة **مرة واحدة**، وتحتها أسماء كل التفاسير التي ذكرتها (لا تكرار).
- الفوائد ملخّصة بإعادة صياغة مختصرة من النصوص الأصلية؛ فارجع إلى الأصل قبل الاستشهاد.
- ما يظهر تحت «تنبيه المحرر» تعليق إضافي ليس من كلام المفسِّر.

## التشغيل

افتح `site/index.html` في المتصفح مباشرة، فلا يحتاج إلى خادم. أما `dist/tafsir.html` فنسخة من ملف واحد فيها كل البيانات، وهي مناسبة للمشاركة.

## التفاسير المعتمدة (٣٧)

**الاختيار الأول:** الطبري، ابن كثير، القرطبي، البغوي، ابن الجوزي، ابن عاشور، البحر المحيط، أضواء البيان، السعدي.

**بالمأثور:** موسوعة التفسير المأثور، الدر المنثور، الثعلبي (الكشف والبيان)، ابن أبي زمنين، السمعاني، السمرقندي.

**الجامعة والتحليلية:** الرازي، الألوسي، الشوكاني، القاسمي، ابن عطية، البسيط للواحدي (ناقص في الملك: ٦ آيات فقط، وشبه كامل في بقية الجزء)، اللباب لابن عادل، ابن القيم، القنوجي.

**المختصرة والمتوسطة:** الوسيط (طنطاوي)، الميسر، المختصر، الجلالين، النسفي، أبو السعود، ابن جزي، الجامع الوجيز، أيسر التفاسير، الماوردي، الثعالبي، الإيجي، مكي بن أبي طالب.

**طُلبت ولا يوجد نصها في المصدر:** تفسير ابن أبي حاتم، البيضاوي، الوجيز للواحدي، تفسير ابن عثيمين.

## البنية

```
data/raw/<n>/          نصوص التفاسير كما نُزّلت (spa5k/tafsir_api)
data/clean/<n>/        النصوص بعد حذف التكرار والتشكيل (للقراءة والاستخراج)
data/benefits/<n>.<tafsir>.json   الفوائد المستخرجة لكل تفسير
data/tafasir.json, data/types.json   تعريف التفاسير والأنواع
data/notes/<n>.json    تنبيهات المحرر لكل سورة (للملك داخل build_data.py)
data/<n>.json          البيانات المدمجة بلا تكرار
scripts/prepare.py     تنظيف النصوص الخام ونص الآيات
scripts/build_data.py  دمج الفوائد وإزالة التكرار والتحقق من الإحالات
scripts/build_site.py  بناء site/index.html و dist/tafsir.html
```

لإضافة سورة جديدة: نزّل النصوص إلى `data/raw/<n>` وشغّل `python3 scripts/prepare.py <n>`، وأنشئ ملفات `data/benefits/<n>.*.json`، ثم شغّل:

```bash
python3 scripts/build_data.py <n> && python3 scripts/build_site.py
```

في ملفات الفوائد، يكون السطر الكامل `{"k":"مفتاح","a":رقم_الآية,"t":"النوع","x":"النص","r":"الإحالة"}`، أما `{"k":"مفتاح"}` وحده فمعناه أن هذا التفسير ذكر فائدة موجودة سلفًا.
